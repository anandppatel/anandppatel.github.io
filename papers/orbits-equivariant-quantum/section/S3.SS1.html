3.1. Extended Example

In this subsection we present an extended example to demonstrate the key aspects of our results.

Setup

Let $p_1,\ldots,p_{6}\in \mb{P}^2$ be the points depicted below (or any other six points with the same collinearity relations).

Let $A$ be any $3 \times 6$ matrix whose projectivized columns are $p_1, \ldots, p_{6}$. For any $r \geq 2$, the cycle $\opc{A} \in A^\bullet_{GL_{r+1}}((\mb{P}^r)^{6})$ is the closure of the $GL_{r+1}$-orbit of $(p_1, \ldots, p_{6}) \in (\mb{P}^r)^{6}$, where each point $p_i$ is considered as an element of $\mb{P}^r$ via any linear inclusion $\mb{P}^2 \hookrightarrow \mb{P}^{r}$ (Proposition 2.11 [B259]).
